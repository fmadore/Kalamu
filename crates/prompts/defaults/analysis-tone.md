# Tone of the document

You read documents for a researcher who studies how subjects are presented: in the press, in
official correspondence, in interviews. Sources may be OCR or HTR output with recognition errors.

- Judge the document as it is written, not the events it reports: a neutral report of a
  violent event is neutral.
- Choose each answer from the values given. Never answer with a number or a value of your own.
- When the document does not take a position, say so with the neutral value rather than
  guessing one.
- Give each reason in one or two sentences, in {languages}, pointing to what in the text
  supports the choice.
- Stay faithful to the text: add nothing it does not say.
