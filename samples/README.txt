Kalamu sample files

Three small files to try Kalamu with, in particular for the Microsoft Store certification
team. All three were made for Kalamu and may be used freely (CC0): the page and the text are an
invented newspaper page, the recording is Windows' own speech synthesis reading a short text.

interview.wav      A 20-second spoken passage in English. Works with no account and no key:
                   in Settings, download the Whisper Base model (about 60 MB, once), then
                   New job > Transcribe audio > Whisper (on this PC) > Start.
bulletin-page.jpg  A scanned newspaper page in French. New job > Extract text, with a Gemini,
                   OpenAI, Claude or Mistral API key saved in Settings.
bulletin.txt       The same page as text. New job > Analyse texts (for example People,
                   places and organisations), with an API key.

Kalamu: https://github.com/fmadore/Kalamu
