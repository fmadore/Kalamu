# 2026-10-28 · Kalamu, two witnesses and warm graphite

## Context

Before the first Microsoft Store submission, the researcher found the app's presentation still
generic. Three things were reviewed together. The name Scriptorium sits one letter from
eScriptorium, the HTR platform of the EPHE used by the same researchers for the same task, so
the confusion was near certain. The icon, three bars on a black tile, read as a "text align" or
menu glyph. The interface had precise rules but the shell every AI tool wears: cool grey
sidebar, black button, a sans name. An exploration (`docs/design/exploration/`, not versioned)
compared names found free of conflicts on the web and in app stores, five icon concepts and
four interface directions drawn with OpenAI GPT Image (`gpt-image-2.5-flare`).

## Decisions

- **The name is Kalamu**, Swahili for pen, from the Arabic *qalam*: it says where the app comes
  from, research on written and oral sources in Africa, and no software of that name was found.
  It is reserved in Partner Center. The GitHub repository keeps its name for now.
- **Everything is renamed**: the crates (`kalamu-*`), the bundle identifier
  (`io.github.fmadore.kalamu`), the exported file formats (`kalamu-pipeline`,
  `kalamu-prompts`), the output name used beside a source of the same name
  (`<file>.kalamu.txt`), the log and the strings.
- **Nothing is lost by installs of 0.1 and 0.2.** On its first start Kalamu moves the
  `io.github.fmadore.scriptorium` data folder to its own name when it has none yet (every
  stored path is relative to it), and moves an API key from the old Credential Manager entry
  the first time the key is read; clearing a key clears both. Pipelines and presets exported
  as `scriptorium-*` still import, and results written as `<file>.scriptorium.txt` are still
  found for a new analysis.
- **The icon is "two witnesses"**: a handwritten sheet behind its transcription, one line under
  the highlighter, on a warm graphite tile. The rendered master (`src-tauri/icons/source.png`,
  its prompt in the `.json` beside it) serves 64px and up; a drawing of the same scene reduced
  to what holds at 16px (`small.svg`) serves 16 to 48px and the sidebar, where the master's
  yellow line vanished.
- **Warm graphite.** The rules of Graphite and highlighter stay as they were; the neutrals move
  toward paper in both themes (same roles and contrasts), the highlighter becomes the brand
  colour as well as "look here", and the app's name is set in Source Serif 4, the one
  exception to the three voices.
- **The strip of pages shows thumbnails** for scans and images: each page small over its number,
  drawn with pdf.js from the same previews as the source pane, lazily as the strip scrolls and
  two at a time, so a 400-page scan does not draw them all at once. Recordings keep numbered
  tiles. `PageImage` and the thumbnails share `src/lib/pdf.ts`.
- **The Store hero image** (`docs/store/hero-1920x1080.png`) is an illustration generated with
  GPT Image, kept with its prompt. A first draft drew pseudo-Arabic script and a skyline of
  minarets; the final asks for abstract strokes and no buildings, so it shows no script it
  cannot read and no cliché.

## Consequences

- Installs of Scriptorium 0.1 and 0.2 are separate apps to Windows: the installer of a newer
  version adds Kalamu beside them, and the old one has to be uninstalled by hand. The next
  release's notes have to say so.
- The privacy policy is dated again, since the data folder and the key entries changed name.
- The catalogue URL, the release downloads and the privacy policy's GitHub Pages address still
  point at the `fmadore/Scriptorium` repository; renaming the repository is a separate step,
  which GitHub redirects for old links.
- DESIGN.md and its `.impeccable` sidecar carry the new values; the decision of 2026-10-25
  still describes the rules, which did not change.
